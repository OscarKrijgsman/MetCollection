# MetCollection
PostgreSQL database with my metallica collection 

I want to build a PostgreSQL data base based on the excel file in this folder. The file contains 4 tabs you need to use:
- CDs
- Vinyl
- 7Inch
- DVD and Boxsets


In the end I want a page I can open in a browser and click through the database. The page should include: 
- Main page with basic statistics on the collection
- A way to click on an 'Era' to get to the lists in the collection (combined CDs, Vinyl, & 7Inch).
- The DVD and boxsets tab should stay a separate 'era' names 'DVD and Boxsets'
- After that I want to filter the list based on the remaining columns in the excel (Format (CD, Vinyl etc), Title, Label, Year, Country and barcode)
- Search bar to search for barcodes and specifics as stored in the database. 

In a later stage I would like to add multiple images to every entry. Please prepare for this already. 
Also, the excel sheets will be updated every now and then, please generate a way to easily add new features. 

Ask question to clarify things before making a plan (export to this folder as PLAN.md). Do not build anything yet.
